# TG-Group 首页介绍文案

> 首页定位：面向 Telegram 群主、社群运营团队和 Bot 管理者的多机器人、多群组管理平台。首页只负责产品介绍与入口引导，不展示未经实现的数据或虚构能力。

## 首屏

**TG-Group**

### 一个控制台，管理所有 Telegram 社群

统一接入多个 Telegram 管理 Bot，集中管理多个群组的安全规则、成员行为与运营配置。网站与 Telegram 管理入口共享同一套账号、权限和配置。

主操作：注册账号 / 登录控制台  
次操作：查看功能介绍

## 核心价值

- **多 Bot 集中管理**：在一个账号下管理多个 Bot，并将 Bot 分配到不同群组。
- **多群组统一配置**：按群组独立配置规则，也可使用模板批量管理。
- **安全与自动化**：围绕入群验证、反垃圾、反广告、成员处罚和审计记录构建管理流程。
- **双端协同**：网站控制台与 Telegram 管理 Bot 共用账号和业务数据。
- **可追溯管理**：关键管理动作记录操作人、对象和时间，便于排查问题。

## 功能介绍

### 入群验证与群安全
当前已接通数学题、字母/数字字母文本验证及可选频道成员资格检查；图片验证码、私聊验证和 CAP 群内验证尚未完成。

### 自动化群管理
围绕广告与垃圾消息识别、关键词规则、自动回复、媒体限制、欢迎通知、成员警告/禁言/踢出/封禁等能力建立统一规则体系。

### Bot 与群组资产
管理多个 Bot 的接入状态、Token 生命周期和群组归属，按租户隔离资源。

### 套餐与授权
提供套餐、订单和授权管理能力；支付渠道及可用币种以正式上线的渠道配置为准。

## 产品原则

- 租户之间的数据与操作严格隔离。
- 网站端和 Telegram 端共享统一权限，不以隐藏按钮代替后端鉴权。
- UI 组件严格使用 shadcn/ui 官方 CLI 生成的官方组件源码，不自制替代基础控件，不混用其他 UI 组件库。
- 不宣传尚未开发、尚未测试或当前无法提供的能力。

## 当前开发状态

截至 2026-11-27，仓库已具备网站账号体系、多 Bot 接入、群组/成员管理、基础规则执行、入群验证、Telegram 管理菜单和警告递进处罚基础流程。后台自动重试恢复、完整群管需求矩阵、双端逐项验收、套餐支付、赞助商及 AI 审核仍在开发中。首页不应将规划能力描述为已交付能力。
