# TG Group Manager SaaS

多商户 Telegram 群管机器人 SaaS 项目。

当前仓库为全新初始化仓库。阶段一将基于 Vue Vben Admin v2（Ant Design Vue）建立管理端骨架，并按项目规范实现五个核心页面的统一间距布局。

## Development baseline

- Frontend: Vue 3 + TypeScript + Vite + Vben Admin v2.11.5
- UI: Ant Design Vue and Vben BasicForm / BasicTable / Page components
- Billing display: integer USDT face value only (1 = 1 USDT)
- Phase 1 gate: five core pages must pass the `gap-4` spacing audit before Phase 2 starts.
